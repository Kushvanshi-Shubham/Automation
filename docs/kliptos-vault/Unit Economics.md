# Unit Economics

**The finding that reshaped the product (verified July 2026).**

## Veo 3.1 API cost
| Tier | Cost/second | 60s short |
|:---|:---|:---|
| Fast | ~$0.12–0.15 | **$7.20–9.00** |
| Standard | ~$0.40 | **$24.00** |
| Hybrid (3× 8s hero clips + Pexels fill) | — | **~$3.00–3.60** |
| Pexels + edge-tts only | — | **~$0.05–0.15** |

## Revenue per video (original plan)
- Pro $19/50cr = $0.38/video · Studio $49/150cr = $0.33 · Top-up $0.50

**⇒ Flat 1-credit-per-video with Veo = losing $7–24 per video (20–60x underwater).**
AutoShorts charges $19–69/mo because stock footage ≈ $0 marginal cost.

## The fix (locked in [[Decisions]])
- Credits are a currency: Pexels = 1 cr · Hybrid Veo = 8–10 cr · Full Veo = 25–30 cr
- Free tier = Pexels only + watermark (~$0.30/user/mo exposure)
- Never "unlimited" anything
- Re-check Veo pricing monthly — falling prices improve margin over time
