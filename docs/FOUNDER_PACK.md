## 4. PROTECTING "KLIPTOS" — patent vs trademark, honestly

**Patent: skip it (for now).** In India, software/business methods "per se" are not patentable (Patents Act Section 3(k)); in the US it's possible but costs $10–25k and 2–4 years, and our edge is execution speed + data, not one patentable algorithm. No shorts-automation competitor holds a meaningful patent.

**Trademark: DO THIS — it's the real protection for "Kliptos".**
- **India:** file at **ipindia.gov.in** (Trade Marks Registry) — classes **9** (software), **41** (entertainment services), **42** (SaaS). ~₹4,500/class (startup/individual rate). Do a public search first (tmrsearch.ipindia.gov.in) for conflicts. You can file yourself or via a CA/IP agent (~₹2–3k extra). Use the ™ symbol immediately; ® after registration (12–18 months).
- **US (when revenue justifies):** USPTO, ~$250–350/class.
- **NOW, free, 10 minutes:** grab the handles — kliptos on X/Instagram/YouTube/LinkedIn + domain (kliptos.com / kliptos.app / kliptos.ai) before anything goes public.

**Company:** for Indian ops, a **Private Limited** (via MCA/SPICe+, ~₹7–15k with a CA) or an LLP; needed before Razorpay live keys and GST. If you later raise US venture money, a Delaware C-Corp (Stripe Atlas, $500) with the Indian entity as subsidiary is the standard flip — don't do it pre-traction.
